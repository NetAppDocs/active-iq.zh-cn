= 在Digital Advisor中查看您的存储系统风险历史记录
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以查看过去三个月内发生的存储系统风险，以便了解这些风险随时间推移的发展情况。

这些风险分为四类： * 未解决 * ， * 新增 * ， * 已解决 * 和 * 已确认 * 。它们以不同的颜色表示。这些风险的摘要通过 * 风险历史记录 * 图来表示。

.步骤
. 在仪表板的*Wellness*窗格中，选择*View All Actions*。
. 选择*Wellness History*。
. 在*风险历史记录*图表中，选择要查看其风险历史记录的类别。
+
当您将鼠标悬停在彩色条上时，它们会显示每个类别中风险数量的信息。选择相应的风险类别后，信息将显示在*风险信息*表中。

+
您还可以下载 Excel 表格中的风险摘要。
