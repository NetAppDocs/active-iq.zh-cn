=== Value Insights 简介

Value Insights 功能整合了 ONTAP 系统的整体运行状况、节省、稳定性和安全信息。您可以通过持续的数据驱动视图来了解 ONTAP 环境，从而使用此信息提高系统运行状况和性能。


NOTE: Value Insights 仅适用于 ONTAP 系统。

详细了解link:https://docs.netapp.com/us-en/active-iq/concept_value_insights.html["价值洞察"]。
